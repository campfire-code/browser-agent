篝火出品

网页自动填表 / 采集助手

用一句话告诉 AI 要做什么，AI 会自己控制浏览器点击、输入、翻页，替你完成重复的填表和采集。

怎么用

  1. 下载 portable.zip 解压，双击启动脚本；首次启动自动安装依赖和 Chromium
  2. 打开 http://127.0.0.1:7788，在 Agent Settings 选 openai 兼容接口，填自己的地址、密钥和模型名
  3. 在 Browser Settings 里选择使用独立浏览器，或沿用自己已登录的浏览器
  4. 在 Run Agent 里用一句话写任务，点 Submit Task，随时可 Stop
交付形式　启动器 portable.zip，在浏览器里操作；界面为英文
